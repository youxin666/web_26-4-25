About This Site

关于本站

这是一个部署在 Cloudflare 上的个人展示网站，用来沉淀文章、项目作品、技术实验、简历资料和联系方式。首页保持简洁，更多说明集中放在这里。

Site Direction

从简历页变成可长期更新的个人主页

网站会继续保留简历与招聘沟通入口，但主线已经调整为个人展示与内容沉淀。后续写的帖子会放在文章区，之前做过的 Cloudflare 部署、D1 数据库、反馈系统、邮箱系统和 AI 岗位匹配，也会拆成一篇篇技术记录。

01 文章

记录实现过程、踩坑、复盘和新工作中的测试学习。

02 作品

展示已上线的网站、实验室入口和嵌入式项目。

03 简历

作为站内一个栏目保留，方便需要时快速查看。

Static First

文章优先静态化

文章、项目页、简历页都作为静态页面输出，不需要每次访问都查询数据库。

D1

数据库只做必要写入

反馈、面试邀约和岗位匹配报告才写入 D1，其余展示内容保持轻量。

Cache

缓存版本号控制更新

CSS 与 JS 使用版本参数，线上更新时能快速刷新，同时避免重复加载旧资源。

Contact

联系、关注与进一步沟通
