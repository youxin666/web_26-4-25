Graduation Project

基于 STM32 的多功能家庭门禁系统

项目负责人（毕设） · 2024.12-2025.05

项目职责

调研家庭门禁系统实际需求，设计多模块功能架构与系统工作流程，制定软硬件协同开发方案；基于 STM32 微控制器完成硬件电路设计与 PCB 绘制，编写指纹识别、RFID 读卡、密码键盘等外设驱动代码。

功能实现

实现 OLED 人机交互界面，完成 OneNET 云平台数据对接，开发手机 APP 远程控制功能；完成单元测试与系统集成测试，持续优化响应速度与运行稳定性。

主控与硬件

STM32F103C8T6、供电/时钟/复位最小系统、PCB 布局、模块焊接与基础功能测试。

身份认证模块

AS608 指纹模块、K210 人脸识别模块、MFRC522 RFID 模块、4x4 矩阵键盘。

交互与执行

OLED 状态显示、SG90 舵机门锁控制、蜂鸣器异常报警，支持连续错误提醒。

联网与远程控制

ESP-01S / ESP8266 Wi-Fi 通信，基于 MQTT 接入 OneNET 云平台，支持 APP 远程开锁、设备状态查询和密码管理。

Embedded Project

基于 STM32 的四足机器人

项目成员 · 2024.06-2024.07

项目概述

基于 STM32 微控制器开发四足机器人控制系统，采用模块化设计实现多自由度运动控制。硬件端通过 3D 打印技术构建轻量化机械结构，集成 SG90 舵机驱动系统与 PCA9685 舵机驱动板实现 8 路 PWM 信号扩展控制。

软件与交互

软件端设计基于三角解析法的步态规划算法，通过 IDY-31 蓝牙模块与 Android 终端 APP 实现实时指令控制，并同步开发 0.96 寸 OLED 人机交互界面显示运动参数。

Result

实现 8 种基础步态控制

项目成果实现四足机器人基础运动控制，响应延迟低于 50ms，可适应复杂地形环境。
