# BTC / ETH / SOL 看盘设计

日期：2026-09-17

## 目标

在 `trading.858846.xyz` 现有市场分组概览中增加 BTC、ETH、SOL 看盘功能。页面复刻参考图的信息结构和交互逻辑，使用免费公开数据源，并沿用现有 Cloudflare 统一快照机制，确保不同访问者在相同币种、周期和快照时间下看到一致数据。

## 范围

本期包含：

- BTC、ETH、SOL 三币种切换。
- 顶部关键指标、价格与 OI 四象限、多周期方向矩阵。
- 价格变化、OI 变化、主动资金流三组横向图。
- 免费 ETF 日度数据展示。
- 从上线时开始累计的 Binance 强平金额。
- 60 秒统一快照刷新、延迟状态和移动端布局。

本期不包含：

- 付费 CoinGlass 或其他付费数据源。
- 跨交易所 OI、资金流和爆仓聚合。
- SOL ETF 的估算或非可靠数据。
- 自动交易、下单或账户数据访问。

## 页面结构

现有页面底部增加固定标签栏：

1. 聚合看板
2. BTC / ETH / SOL 看盘

看盘页面采用参考图式左右分栏：

- 顶部：BTC、ETH、SOL 切换和数据更新时间。
- 指标行：当前价格、当前 OI、账户多空比、ETF 净流入、资金费率、24h 爆仓。
- 左栏：价格变化为横轴、OI 变化为纵轴的四象限。
- 右栏上部：15m、30m、1h、4h、8h、12h、24h 方向矩阵。
- 右栏下部：价格变化、OI 变化、主动资金流三列横向图。

桌面保持左右分栏；移动端依次排列指标、方向矩阵、四象限和三组图，不产生页面级横向溢出。

## 数据口径

### Binance 实时数据

- 价格变化：当前 USDⓈ-M 永续价格对比滚动周期起点价格。
- OI 变化：当前实际持仓数量对比滚动周期起点持仓数量。
- 当前 OI：实际持仓数量乘以当前价格得到估算美元名义价值。
- 原始资金流：周期内主动买入成交额减主动卖出成交额。
- 账户多空比：Binance 全市场账户多空比。
- 资金费率：Binance 当前永续合约资金费率。
- 爆仓金额：从功能上线后订阅或轮询 Binance 强平公开数据，自行累计。

滚动周期统一为 15m、30m、1h、4h、8h、12h、24h。底层历史序列采用可支持滚动窗口的细粒度数据，不使用固定周期边界替代滚动变化。

### ETF 数据

- BTC、ETH：使用无需付费密钥的公开日度净流入数据，展示数值、数据日期和来源。
- SOL：没有可靠免费数据时显示“暂无数据”。
- ETF 日度数据不得标记为实时数据。

### 多空方向

- 价格上涨、OI 上涨：多头增仓。
- 价格下跌、OI 上涨：空头增仓。
- 价格上涨、OI 下跌：空头止损。
- 价格下跌、OI 下跌：多头止损。

四象限与方向矩阵复用同一组价格/OI 变化值，避免同页面内出现口径分叉。

## 数据流与一致性

采用“浏览器采集候选数据 + Cloudflare Durable Object 统一快照”方案：

1. 能访问 Binance 的浏览器按当前币种和所需周期采集公开数据。
2. 浏览器把候选数据提交给 Worker。
3. Worker 校验币种、字段、数值范围和时间戳。
4. Durable Object 在刷新窗口内锁定唯一快照。
5. 所有访问者读取同一份快照，不直接展示各自采集的候选数据。

统一快照每 60 秒允许更新一次。页面隐藏时暂停自动采集；恢复可见后立即检查快照并按需刷新。

## 组件边界

- 聚合看板：保留现有功能和数据逻辑。
- 看盘导航：负责聚合看板与币种看盘视图切换。
- 币种选择器：只管理 BTC、ETH、SOL 当前选择。
- 指标摘要：渲染单币种顶部指标及各自更新时间。
- 四象限：根据选定展示周期渲染价格/OI 坐标。
- 方向矩阵：渲染七个滚动周期的方向标签。
- 周期条形图：分别渲染价格、OI、资金流数据。
- 快照客户端：获取、提交并缓存统一快照。
- Durable Object：校验、锁定和返回统一快照。
- 爆仓累计器：保存累计起点、方向和金额。

## 异常处理

- Binance 部分请求失败：保留上一份有效快照并标记“数据延迟”。
- 单项数据缺失：显示 `—`，不生成演示或估算百分比。
- ETF 数据：始终显示独立数据日期。
- 爆仓累计不足 24 小时：显示“自 HH:mm 起累计”。
- 快照不可用：显示明确错误状态，不影响聚合看板。
- 数据提交不通过校验：拒绝写入并继续提供上一份有效快照。

## 安全与权限

- 不读取 Binance 账户数据，不需要 Binance API Key。
- 第三方密钥不放入浏览器；本期免费方案不引入第三方密钥。
- Cloudflare 部署只使用 `CLOUDFLARE_API_TOKEN_LUOWENHUI` 和 Account ID `7722052fdf1845b1b5e987938bb735f3`。
- 服务端对候选快照进行币种白名单、字段类型、数值范围和时间新鲜度校验。

## 验收标准

- BTC、ETH、SOL 切换不触发整页刷新。
- 三个币种均能展示顶部摘要、四象限、七周期方向和三组周期图。
- 四象限位置与价格/OI 正负方向一致。
- 60 秒后快照时间更新，实时指标能随市场数据变化。
- 两个独立浏览器在相同币种、周期和快照时间下显示完全相同的数据。
- 免费 ETF 数据显示来源与日期；SOL 缺失时显示“暂无数据”。
- 爆仓数据明确显示累计起点，且不会冒充完整 24 小时数据。
- 1920px 桌面符合参考图的左右布局。
- 390px 手机宽度无页面级横向溢出，内容顺序符合移动端设计。
- 原有聚合看板、TOP5/TOP10、统一周期和独立周期功能保持正常。
- JavaScript 语法检查、Worker dry-run、生产页面交互及真实浏览器截图验证通过。
