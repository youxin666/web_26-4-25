# 手机端弧形文章叠卡设计

## 目标

把手机端文章缩略卡从直线叠放改为参考图中的弧形卡片带，并进一步缩小上方当前文章的大图。当前卡片继续从卡片带的左下端抽出，切换后上方预览同步更新。

## 范围

- 只修改宽度不超过 `720px` 的圆柱模式。
- 桌面端三维圆柱、博客侧栏、单栏和双栏布局保持不变。
- 文章数据、封面来源、自动主题图和链接结构保持不变。

## 弧形卡片带

1. 当前卡片位于卡片带左下侧，并与叠层保持清晰间距。
2. 非当前卡片依据循环顺序映射到归一化参数 `t`，范围为 `0` 到 `1`。
3. 水平位置随 `t` 线性向右展开；垂直位置使用正弦缓动向上弯曲，使前半段上升明显、后半段逐渐趋于水平。
4. 卡片沿弧线逐渐缩小、降低亮度和透明度，并轻微旋转，形成连续纵深，不呈现为对角直线。
5. 至少四张非当前卡片必须清楚露出边缘；卡片组不得产生页面横向溢出。
6. 当前卡保持 `48px` 基础宽度，仅通过位置、层级、亮度和描边突出，不重新放大成主视觉。

## 当前文章预览

- 手机端预览图片高度调整为 `clamp(11rem, 28vh, 15rem)`。
- 分类、标题和“查看这篇文章 +”链接保持现有顺序。
- 图片继续使用 `object-fit: cover`，避免改变舞台宽度或拉伸封面。
- 舞台保留足够空间显示操作链接、抽出卡和弧形卡片带。

## 交互与状态

- 保留拖动、点击露出卡片、左右方向键和回车操作。
- 切换时旧卡回到弧线，新卡从弧线起点抽出。
- 抽出卡的 `aria-label`、上方预览标题和文章链接始终对应同一文章。
- 中英文切换后重新初始化弧形卡片状态。
- 减少动态效果模式取消位置过渡。

## 验证标准

- 源码契约测试验证弧线使用正弦函数，而不是固定的线性 `y` 步长。
- 390×844 生产截图中，卡片轨迹从左下向右上弯曲，后段趋平。
- 手机预览图片计算高度不超过 `15rem`，且明显低于修改前的 `21rem`。
- 拖动后抽出卡与上方预览同步，页面无横向溢出。
- 桌面端仍使用 `matrix3d` 圆柱变换，右侧栏仍显示。
