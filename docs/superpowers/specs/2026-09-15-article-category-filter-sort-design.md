# 文章归档分类筛选与排序设计

## 目标

在 `/articles` 文章归档页增加分类筛选与发布时间排序，让访客能快速缩小文章范围，并确保刷新、分享链接及浏览器前进后退后仍保留选择。

## 范围

- 仅修改博客文章归档页及其共享前端资源。
- 保留现有单栏、双栏和圆柱排列切换。
- 不增加新的后端接口；使用页面已有的文章数据在前端筛选与排序。
- 不改变文章分类名称及文章数据结构。

## 界面设计

### 桌面端

- 沿用右侧“文章分类”卡片。
- 在分类列表首项增加“全部”，随后显示现有分类及各自文章总数。
- “全部”和各分类均为可点击按钮，并显示明确的当前选中状态。
- 在分类列表下方增加排序控件，选项为“最新发布”和“最早发布”。

### 手机端

- 因右侧栏在手机端隐藏，在文章列表上方增加一行紧凑筛选工具栏。
- 工具栏包含分类选择器和排序选择器；空间不足时仍保持同一行，控件各占可用宽度。
- 控件触摸目标不得小于现有移动端表单控件标准，文字不得低于 16px，避免 iOS 聚焦缩放。

## 状态与 URL

- 默认状态：全部分类、最新发布。
- URL 参数：
  - `category`：分类名称；省略表示全部。
  - `sort=oldest`：最早发布；省略或 `sort=latest` 表示最新发布。
- 用户改变分类或排序后，使用 History API 更新 URL，不整页刷新。
- 浏览器前进或后退时，从 URL 恢复筛选、排序和控件状态。
- 未知分类回退到“全部”；未知排序值回退到“最新发布”。

## 数据处理与分页

1. 从页面现有文章数据取得完整列表。
2. 按分类筛选。
3. 按发布时间升序或降序排列。
4. 在筛选和排序完成后分页。

- 单栏模式每页 5 篇。
- 双栏模式每页 10 篇。
- 圆柱模式展示当前筛选后的全部文章，不分页。
- 改变分类或排序时自动回到第 1 页。
- 改变排列方式时保留分类与排序状态。
- 分类旁的数量始终为全部文章中的原始总数，不随当前筛选结果改变。

## 文案与空状态

- 中文：全部、最新发布、最早发布、该分类暂无文章。
- 英文：All, Newest first, Oldest first, No articles in this category.
- 筛选结果为空时隐藏分页并显示空状态；用户可以直接切换回“全部”。
- 分类和排序控件具有可读标签、键盘焦点和当前选中语义。

## 样式约束

- 复用现有文章侧栏、表单控件、主题色、圆角、边框和深色模式变量。
- 不改变文章卡片、顶栏或侧栏整体宽度。
- 桌面端与手机端使用同一筛选状态源，避免两套控件不同步。

## 错误与边界处理

- 分类比较使用页面数据中的原始分类名称，URL 使用标准编码。
- 缺失或无效日期保持稳定顺序，不导致页面脚本报错。
- 文章列表为空时仍显示“全部”和排序控件，以及明确空状态。
- 切换语言后重新渲染控件文案，但不改变已选分类与排序。

## 验证标准

- 自动测试覆盖默认状态、分类筛选、升降序、无效 URL 参数、分页顺序及中英文文案。
- 桌面浏览器验证右侧分类卡交互、排序、URL 更新和返回恢复。
- 390px 手机视口验证顶部紧凑控件、16px 字号、筛选结果和无横向溢出。
- 验证浅色、深色、单栏、双栏和圆柱模式下状态一致。
