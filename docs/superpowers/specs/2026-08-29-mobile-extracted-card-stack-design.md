# 手机端抽出式文章叠卡设计

## 目标

将文章归档页圆柱模式的手机端缩略图区域改为参考站风格的紧密叠卡：非当前卡片集中重叠在右下角，当前卡片从卡组中向左上方抽出。上方文章预览继续展示当前文章的分类、标题、大图和操作链接。

## 范围

- 只修改宽度不超过 `720px` 时的圆柱缩略图布局和切换动画。
- 桌面端继续使用现有三维圆柱布局。
- 单栏、双栏文章布局不变。
- 上方当前文章预览结构、数据来源和文章链接不变。

## 视觉结构

1. 缩略图组位于预览舞台右下角，不造成页面横向溢出。
2. 非当前卡片缩小约 40%，以高重叠率排列；每张只露出一段图片边缘，形成连续卡片库。
3. 卡片仍只显示上传封面或网站自动生成主题图，不显示标题、摘要或元数据。
4. 当前卡片从叠层中向左上方抽出，和卡组主体之间产生明确间距。
5. 当前卡片略微放大、提高亮度并提升层级；其余卡片依据与当前索引的距离降低亮度和透明度。
6. 抽出卡片仍明显小于上方文章预览，不与“查看这篇文章 +”链接重叠。

## 交互

- 保留触摸拖动、鼠标拖动、点击非当前卡片、左右方向键和回车进入文章。
- 切换完成后，旧卡片退回叠层，新卡片从对应位置抽出。
- 上方预览和抽出卡片始终指向同一篇文章。
- 拖动时不触发文章跳转。
- 动画短促平滑；启用减少动态效果时取消抽出过渡。

## 实现边界

- 继续复用 `renderCylinderArticleCard()` 的纯图片卡片结构。
- 在 `initArticleCylinder()` 的手机端渲染分支中计算线性叠卡位置、层级、缩放和透明度。
- 桌面端继续使用现有 `rotateY(...) translateZ(...)` 圆柱变换，不受手机叠卡逻辑影响。
- 当前索引、吸附、预览同步和语言切换继续由现有控制器管理，不新增后端接口。

## 响应式与可访问性

- 以 `720px` 为手机端分界，与现有样式保持一致。
- 390×844 视口下至少能辨认四张非当前卡片的露出边缘。
- 当前卡片可触控，其他卡片仍可通过点击其露出区域切换。
- 每张缩略图继续使用文章标题作为 `aria-label`；非当前卡片不进入 Tab 顺序。
- 中英文切换后，当前卡片和上方预览保持同步。

## 验证标准

- 契约测试区分手机叠卡变换和桌面圆柱变换。
- 390×844 生产浏览器截图中，卡片组位于右下角、非当前卡片紧密重叠、当前卡片明显抽出。
- 触摸或指针拖动后，旧卡片回到叠层，新卡片抽出，上方预览标题发生对应变化。
- 手机端无横向页面溢出，侧栏继续隐藏。
- 桌面端圆柱和博客侧栏保持现状。
- 中文和英文各验证一次操作文案与预览同步。
