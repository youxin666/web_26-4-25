# 桌面端弧形文章叠卡设计

## 目标

将文章归档圆柱模式的桌面端缩略图从三维圆柱改为与手机一致的弧形卡片带：卡片从左下向右上沿正弦曲线延伸，当前卡从弧线左侧抽出。桌面右侧博客侧栏继续保留。

## 范围

- 修改宽度大于 `720px` 时的缩略卡片渲染方式。
- 手机端现有正弦弧线保持不变。
- 单栏、双栏、上方文章预览和文章数据结构保持不变。
- 文章分类、最近文章和 RSS 等桌面侧栏保持现有布局。

## 桌面弧线

1. 弧形卡片带位于文章预览舞台右下角，不进入侧栏区域。
2. 非当前卡片使用与手机相同的归一化参数 `arcT` 和正弦高度函数。
3. 桌面使用独立的水平跨度、垂直跨度和卡片宽度；卡片比手机略大，但明显小于上方预览图。
4. 弧线从左下向右上延伸，前段上升明显，后段逐渐趋于水平。
5. 卡片沿弧线逐渐缩小、降低透明度和亮度，并带有轻微旋转。
6. 当前卡从弧线左侧抽出，提高亮度、描边和层级，不与“查看这篇文章 +”链接重叠。

## 响应式参数

- 手机端继续使用 `48px` 基础卡宽和现有弧线参数。
- 桌面端基础卡宽控制在 `76px` 至 `92px`。
- 桌面弧线占内容舞台宽度约 `42%` 至 `50%`，固定在右下区域。
- 卡片带和抽出卡必须被舞台裁剪，不产生页面横向溢出。

## 交互与状态

- 手机和桌面共用当前索引、拖动、点击、方向键、吸附和预览同步逻辑。
- 桌面端不再设置 `rotateY(...) translateZ(...)` 或圆环整体 `matrix3d` 变换。
- 切换时旧卡回到弧线，新卡从左侧抽出。
- 抽出卡标题、文章链接和上方预览始终一致。
- 中英文切换后重新初始化弧形状态。

## 验证标准

- 源码契约测试证明桌面和手机都进入弧形卡片渲染器，并使用不同几何参数。
- 1440×1000 生产浏览器中，卡片中心形成前陡后缓的上升弧线，且只有一张抽出卡。
- 桌面侧栏显示为 `grid`，弧形卡片带不与侧栏重叠。
- 拖动后抽出卡与上方预览同步，无横向页面溢出。
- 390×844 手机弧线、较小预览图和隐藏侧栏保持不变。
